This repository contains the code to reproduce the following experiments
from the paper "A Gaussian process approach facilitates the identification of robust biomarkers for exposure to complex pesticide mixtures" by Ruben Bakker, Yuliya Shapovalova, Tjeerd M.H. Dijkstra, Tom Heskes, Cornelis A.M. van Gestel, Katja Hoedjes1.

The following folders contain:

- data: the gene expression data used to fit the models; 
- experiments: code for fitting the models on real gene expression data;
- reproduction: synergy modeling of reproduction data;
- filtering: example of filtering genes based on concentration-depndent and constant models just for a single compound;
- simulations: generation of simulated data and fitting the models on the simulated data. 
- utils: contains code for building Gaussian processes models proposed in the paper.
